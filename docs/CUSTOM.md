# Custom scaling strategies (`appdimens.custom`)

Port of `appdimens-dynamic` **library-custom**. Same JSON document, same text-formula language, same
built-ins and presets as Android, iOS, Flutter, React Native, Web, .NET, KMP and Games; the test suite
reproduces the shared 540-case fixture (`tests/custom-strategy-fixture.json`) generated by the Kotlin
reference engine.

```python
from appdimens import custom as c

# 1. A factor from code (computed once per screen)
product = c.custom_scale_strategy(lambda s: s.clamp(s.width / 360, 0.85, 1.8))

# 2. A formula (code or text) — `base` is the value you pass
hud = c.scaling_formula("base * pow(sw / 360, 0.8)")
hud2 = c.scaling_formula(lambda f: f.base * f.pow(f.sw / 360, 0.8))

# 3. A full strategy, or the shared JSON document
c.load_scaling_strategies(open("custom-strategies.json").read())   # registers ids, sets "default"

c.cdp(16, product)          # dp through the current scope (window)
c.cdp_px(16, "brand")       # px, by id
c.csp(14, hud)              # text dp with the strategy's font-scale policy
c.cdp(16, "base * (sw / 360)")   # a text formula used directly (parsed once, shared)
```

Pass `target=` (a `ScreenSnapshot`, `Metrics` or `Dimens`) to evaluate against a specific screen; by
default the current `appdimens` scope is used, so every adapter (Tkinter, Qt for Python, Kivy, pygame,
Blender …) gets custom strategies with no extra wiring.

| Function | Result |
|---|---|
| `cdp(v, s)` / `cdp_px(v, s)` | layout value in dp / px |
| `csp(v, s)` / `csp_px(v, s)` | text dp / px, font-scale policy applied (`follow`, `ignore`, `{max}`) |
| `csp_units(v, s)` | text for toolkits that apply the system font scale themselves |
| `strategy.explain(target)` | factor, axis, ratio, curve, clamps and applied rules |

JSON document (`{"version": 1, "default": …, "strategies": [...]}`): `extends` (a built-in, preset or
another id), `reference`, `axis` (`smallestWidth|width|height|min|max|diagonal|perimeter`), `curve`
(`linear|power|logarithmic|interpolated|constant|breakpoints|expression`), `multiplier`, `clamp`,
`valueClamp`, `aspectRatio`, `sensitivity`, `fontScale`, `ignoreMultiWindow`, `formula` and `rules`
(`when: {device, orientation, smallestWidth/width/height/aspectRatio {min,max}, multiWindow}`, `set`).
Built-ins: `scaled power logarithmic interpolated diagonal perimeter fixed`; presets:
`tabletFriendly compactFirst tvSafe wearable gameHud readableText`.

Errors are strict and atomic: a malformed document raises `ValueError` with its JSON path and leaves
the registry untouched. Full language and format reference:
[appdimens hub — DOCS/CUSTOM.md](https://github.com/bodenberg/appdimens/blob/main/DOCS/CUSTOM.md).
